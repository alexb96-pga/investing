# investing

Personal investing research scripts.

| File | What it does |
|---|---|
| [`roro/roro_risk_score.py`](roro/README.md) | Risk-On / Risk-Off score (0 to 1) from 12 live market and macro signals |
| [`macro_outlook`](macro_outlook_README.md) | Tests how well FRED macro indicators and Shiller CAPE correlate with S&P 500 monthly returns |
| [`normalised_buffet_ind`](normalised_buffet_ind_README.md) | Plots the Buffett Indicator (S&P 500 / GDP) as standard deviations from its long-run trend |

Scripts that call FRED need a free API key: https://fred.stlouisfed.org/docs/api/api_key.html

For research and education only, not financial advice.
